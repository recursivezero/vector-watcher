# Requirements

The development environment requires the following tools.

## Required Software

Install:

- Node.js v22.21.1
- npm v10.9.4
- Rust v1.98.0
- Cargo v1.98.0
- Python v3.12.3
- Poetry v2.2.1

---

## Verify Installation

Run:

```bash
node --version
npm --version
python --version
poetry --version
cargo --version
```
