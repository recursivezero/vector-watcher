# Tables

Vector Watcher allows users to inspect available tables from a connected database.

![Table List](screenshots/database-tab.png)

---

## Table Metadata Information

Depending on the current Vector Watcher implementation, table information may include:

- Table name
- Schema
- Number of records
- Columns
- Metadata
- Vector or embedding fields

---

## Browsing Records

- Pagination
- Record limits
- Column visibility
- Sorting
- Filtering

Only include functionality that exists in the current release.
